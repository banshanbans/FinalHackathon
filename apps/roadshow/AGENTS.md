# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

The selected opening source is `references/orbital-precision.png`; the approved terminal composition reference is `../../outputs/m35-presentation-design/qa-interaction-1920x1080.png`. This project is a completely independent roadshow build: do not import source code, runtime state, or APIs from `apps/presentation`, `apps/web`, or the simulation backend. Keep all production assets local. The visual language is Apple-inspired rather than an Apple clone: full-bleed black canvas, one monumental geographic subject, restrained teal semantics, a single blue action color, and no dashboard cards or glassmorphism.

The outward brand is `13110`. `PolicyScope` may remain only in internal package/history identifiers and must not appear in browser metadata, visible copy, accessibility labels, loading/error states, or the Presentation-stage brand position. The semantic scene chain now continues through `orbital → china-focus → identity-reveal → causal-handoff → policy-signal → province-agent → vehicle-interior → enterprise-agent`. The identity reveal explains `1 中央政策研判 / 31 省份模拟主体 / 10 车企模拟主体` without implying real institutional or corporate decisions.

The opening prelude is one reversible, wheel-driven shot with two distinct camera moves: `dark cockpit → cockpit alone reaches half illumination → remaining cockpit and display illuminate together while a nonlinear approach stops inside the cabin → fixed camera while subsidy pages transform → final center-display dolly → live Earth → China focus`. It must not autoplay. The first approach may enlarge the cockpit only to `1.48×` and must hold that scale throughout the explainer; it may not leave the cabin. It uses the selected local cockpit asset with no automaker logo. The display is a transparent aperture onto the same persistent WebGL Canvas, not a video, second Canvas or page transition. The final cockpit and Canvas dolly is centered and quintic, and the first settled Earth frame must not reveal the `13110` wordmark yet.

Before the live Earth appears, the center display owns the approved subsidy explainer chain: `generic consumer subsidy → central/local responsibility → 100-share funding pool → west/central/east ratio presets → one ratio change → four policy-ripple domains`. Use shares, never fake currency amounts. The funding pool, ratio ring, ripple ring and Earth are one continuous circular subject. Do not add an ecommerce brand, traditional dashboard, information-feed page or a second visual system.

The circular continuity is literal, not a crossfade between lookalike circles. One persistent `.circle-bridge` owns the visible edge from the funding pool through the ratio instrument and ripple. It moves and resizes while the camera is fixed, emits two restrained concentric ripples, then centers, expands, gains a cyan atmospheric glow and crossfades into the matching live WebGL Earth rim. The old pool/ratio/ripple content containers must not draw competing borders.

The approved Scene 00 → Scene 01 transition must remain one continuous spatial shot. The camera actively pushes toward China while the China layer stays attached to the globe; only after the close approach may the same geometry conform into the national-map view. The map must never lift toward the audience as an independent object. This is one continuous dolly: globe scale remains exactly `1`, the camera never pulls back, the projection handoff cannot introduce a second zoom, and camera progress uses a quintic nonlinear ease with zero endpoint velocity and acceleration. Do not crossfade to a separate SVG/page-like chapter; wheel progress owns the complete opening from the dark cockpit to the stable causal handoff.

The national-map view must preserve one-China map completeness: Taiwan, Hong Kong and Macao remain visible within the same national geography as non-simulation context, and the South China Sea islands inset must remain visible in the stable national frame. Its geometry must be derived from the frozen local Ministry of Natural Resources standard-map source; do not hand-draw, approximate or fetch map geometry at runtime.

Wheel and trackpad input must drive a virtual progress target while one GSAP ticker smooths the paused master timeline. Each animation beat intentionally requires long travel: pixel-wheel progress uses a 4200px normalization denominator and a 0.065 per-event cap. The document itself must remain viewport-locked: real page displacement caused repeatable macOS WebGL compositor failures on the user's machine. Do not create a tween per wheel event or add a second smoothing layer. Avoid per-frame React/Zustand updates when the semantic stage has not changed.

Keyboard navigation shares that same reversible virtual timeline: `ArrowRight` and `ArrowDown` advance, while `ArrowLeft` and `ArrowUp` rewind. The first half of the complete story (`0–1.56`) uses a precise `0.05` step per key event; the second half uses `0.1`. Key input must never hard-cut chapters, move the native document, remount WebGL, or bypass the GSAP ticker smoothing.
The `.roadshow` stage is a focusable keyboard surface: it takes focus when data is ready and recaptures focus on pointer interaction so embedded browser panels deliver arrow keys to the experience.

The latest approved ratio page includes a scroll-driven spatial slider. It must show all three presets simultaneously and move through `85/15 → 90/10 → 95/5`, synchronizing the large ratio, slider thumb/fill and active regional preset. It is a narrative control inside the fixed cockpit display, not a form input or a claim that the system has optimized policy.

Keep the full-screen WebGL stage fixed and prevent native document scrolling. Sticky or natively scrolling GPU canvases produced black compositor invalidation rectangles and crash-like flashes during active wheel/trackpad input on macOS; do not reintroduce either path.
