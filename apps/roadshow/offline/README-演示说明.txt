13110 路演离线包
=================

使用方法
1. 先将整个文件夹复制到电脑本地，不要直接在压缩包内运行。
2. macOS：双击“启动13110.command”。
   如果系统首次拦截，请右键文件 → 打开 → 再确认打开。
3. Windows：双击“启动13110.bat”。
4. 浏览器会自动打开 http://127.0.0.1:13110/

现场操控
- 鼠标滚轮/触控板：连续推进或回退。
- 右键、下键：推进。
- 左键、上键：回退。
- 如果方向键没反应，先单击一次画面。
- 推荐 Chrome 或 Edge 全屏演示；进入全屏可按 F11。

注意事项
- 不需要联网，不需要安装 Node、Python 或 npm。
- 不要删除 site、13110-server（Mac）或 server-windows.ps1（Windows）。
- 演示结束后，关闭浏览器和名为“13110 Server”的终端窗口即可。
- 正式路演前务必在最终演示电脑上完整走一遍，并关闭系统更新、通知和省电模式。
