# PolicyScope M29 可信数据层

本目录是 V3.2 之后独立建设的真实事实层，不回写或覆盖 V3.0/V3.1 冻结数据。

## 基线规则

- 同一指标族 31 省均具备可比 2025 数据时采用 2025，否则整组回退 2024；不同年份原值继续保留。
- 直接来源与具备合理置信度的统一推算均纳入“可信数据”。
- 用户界面和工作簿只显示“可信数据”；机器层保留直接来源、推算公式、原值与方法版本。
- 原值、单位、统计期、主体口径、机构、原始链接、标题或章节、获取日期、转换和缺失处理必须完整保留。

## 事实与推断分层

1. `raw_fact`：省级经济、产业、市场、政策、节点、企业和物流的原始事实。
2. `relation_fact`：带方向、类型、主体、有效期和状态的省际关系。
3. `derived_feature`：从原始事实确定性生成、可反算的指标。
4. `persona_prior`：结构事实与历史政策证据形成的稳定先验。
5. `scenario_assumption`：观察 Peer、事件权重及其他明确的模型假设。

## 省际关系规则

- `observation_peer`、`competition_peer`、`coordination_peer` 分别存储，不相互替代。
- 企业总部、生产基地、资本投资、货物流、技术协作、政策协议和物流通道使用不同关系类型。
- 在建、规划、历史、终止和现行关系必须有独立状态及有效期。
- 省内关系不得进入省际边；多省网络不得在无证据时展开为全连接双边关系。

活动快照版本为 `nev-m29-2025-v2`，清单位于 `snapshot_manifest_v1.json`。当前包含 292 个来源、4527 条可信事实、65 条政策事实、48 个产业节点、90 条关系事实、711 个派生特征和 1488 条公路/铁路距离；177 项需求全部为 `accepted_trusted`。主工作簿位于 `outputs/m29_real_fact_integration/`，六个原始附件未被修改。
