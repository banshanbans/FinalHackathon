# ADR-340：M31 显式决策与互动主画布

日期：2026-08-13  
状态：实施与验收中

## 决策

M31 将 M30 的上下文驱动协作升级为可审计的明确决策，但不新增主体、政策工具、主路由或结构化主体调用。双分支调用预算保持 226 次。

- 省级 3A 对省际协同与省企资源包分别可发起 0–2 项；两类名额相互独立。未发起资源包必须保存原因、机会成本和改变条件。
- 省企资源包只调度既有省级财政空间与三类补贴配置。车企最终轮对每个收到的资源包只可 `accept` 或 `reject`，且每车企每分支最多接受 5 项。
- 有效省企匹配必须同时具备有效提议、明确接受和双方资源合法性。环境只通过渠道协同与产业协同两项机制计入贡献；拒绝、未发起和资源无效的贡献恒为零。
- 车企对 31 省始终给出 `expand`、`maintain` 或 `reduce` 的明确市场决定，并记录主承诺、机会成本、拒绝理由和重新评估条件。内部排序只可作为 Evidence，不进入主结果模型或页面。
- Live 默认展示“干预方案 − 原始方案”差异地图与互动决策台。地图使用相同的 31 省分析衍生底图、动态色阶与空值纹理规则；不因图层切换触发主体调用。

## 版本与隔离

M31 使用 `province-resource-envelope-v2`、`province-action-v7`、`automaker-action-v4`、`decision-trace-v3`、`branch-v7`、`world-state-v8`、`comparison-v8`、`event-v8`、`strategy-market-v2` 和 `nev-policy-env-v5`。缓存命名空间为 `v3_2_m31_*`，不得转换或覆盖 M30 对象、缓存或冻结标准地图。

## 后果

用户可以直接观察谁主动发起、谁明确拒绝、哪些互动生效及其机制贡献，而不会把候选池误解为主体已经作出的决定。省企资源包是机制实验中的模拟协同，不构成现实招商、供应合同、建厂或投资承诺。
