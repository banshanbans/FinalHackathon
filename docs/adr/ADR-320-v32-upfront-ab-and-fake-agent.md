# ADR-320：V3.2 前置直接 A/B 与 Fake Agent 重构

- 状态：Accepted
- 日期：2026-08-12

## 决策

V3.2 将用户旅程改为“政策输入 → 中央解读 → 实验设计 → 基线确认 → 推演运行 → 结果复盘”。基线确认时从同一不可变快照派生双分支，不再使用运行期年末干预或事件审批。

三种实验类型在 Schema 验证中强制唯一主动差异。每分支执行五轮、同轮隔离的 Agent 链路，最终指标由确定性环境结算。

V3.2 通过新 `policy_text` 请求分流；旧 `objective` 请求和 V3.1 API 继续服务历史对象。V3.2 对年末干预和运行期事件审批返回稳定不兼容错误。

## 数据与解释边界

现有省级 Profile、关系和车企基线在 V3.2 均保持 `proxy`。`DecisionTrace` 是结构化行动证据，不是模型思维链；`confidence` 对用户显示为“依据完整度”，不是概率。M29 真实事实层迁移仍为后续独立工作。
